## Numbers

## What the reviews caught (all fixed before merge)
- 045: the spam guard never kicked floods under about 200 requests per second.
- 047:
  - player names were shown as rich text (a name could break the lobby for everyone);
  - returning a held item skipped the place check.
- 048:
  - prompts named the default keys after a rebind;
  - key capture leaked into the game.
- 049: the performance check's baseline only ever got stricter.
- 006:
  - the vegan rule (D27) was not enforced on generated text;
  - the upstream answers had no size limit.
